# 方寸证件照 · 微信小程序

一款微信小程序证件照工具：上传自拍 → AI 智能抠图换底色 → 按规格自动构图 → 美颜 → 一键保存到相册。

---

## 一、核心能力

| 能力 | 说明 |
|---|---|
| AI 人像抠图 | 腾讯云「人体分析」SegmentPortraitPic，边缘质量高，发丝干净 |
| 换底色 | 白 / 蓝 / 红 / 浅灰 / 深蓝，云端合成 |
| 26 种规格 | 常用（一寸/二寸/小一寸/大一寸/小二寸/大二寸）+ 证件（身份证/社保卡/驾驶证/护照/港澳通行证/台湾通行证/教师资格证/工作证）+ 签证（通用/申根/美国/日本/韩国/英国）+ 考试报名（考研/教资/四六级/普通话），支持自定义尺寸 |
| 规格自动构图 | 按「头高占 2/3、头顶留白、水平居中」的证件照规范自动摆位 |
| 美颜 | 磨皮 / 美白 / 红润，保边处理，上限刻意压低不改脸型 |
| 内容安全 | 上传前做图片内容审核（色情/暴恐/违禁），非人像自动拦截 |
| 上传扫描动画 | 上传后扫描光带动画 + 分阶段提示，成品淡入 |

## 二、架构

```
小程序端                        云函数(segment)                    腾讯云
────────                        ──────────────                    ──────
选择照片                         接收 base64
压缩(≤700px, 自适应降档)  ──→     内容审核(并行)            ──→  ims.ImageModeration
                               人像分割                  ──→  bda.SegmentPortraitPic
                               人像合理性校验(主体占比+肤色)
                               合成底色 / 按规格输出
显示成品图(<image>)  ←──────────  返回成品图 JPEG
一键保存(直接存, 零二次压缩)
```

- **成品图直接显示，不走画布**，少一层处理少一处卡死风险
- **保存直接存原文件**，不重新编码，画质零损失
- 腾讯云密钥只存云函数**环境变量**，不进客户端（防反编译泄露）

## 四、跑起来

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 「导入项目」选择本目录，填入你自己的 AppID
3. 云函数部署：
   - `cloudfunctions/segment` 上传部署（或 `npm install` 后用开发者工具右键上传）
   - 配置环境变量：`TENCENT_SECRET_ID`、`TENCENT_SECRET_KEY`、`TENCENT_REGION`（如 ap-shanghai）
   - 开通腾讯云「人体分析」（人像分割）与「图片内容安全」服务
4. 小程序后台配置 request 合法域名（云函数 HTTP 访问地址）
5. 编译，真机预览（相册权限需真机）

> 本地 `model/portrait.onnx` 是兜底模型，约 25MB，需自行放入 `cloudfunctions/segment/model/`。未放置时，未配置腾讯云密钥的请求会走不到本地兜底，但腾讯云主通道不受影响。

## 五、关键实现说明

- **TC3-HMAC-SHA256 签名**：云函数内手写签名，不引 SDK，避免部署包过大
- **PNG 解码**：自写极简 PNG 解码器（zlib inflate + 5 种 filter），处理腾讯云返回的遮罩
- **内容审核并行**：审核与切图同时发起，总耗时 = 较慢的那个，不额外等待
- **非人像拦截**：主体占比 3%~97% + 上半身肤色 ≥1.5%，不满足则返回 NO_FACE
- **自适应上传**：base64 超限自动降档重压，规避云函数网关 413
